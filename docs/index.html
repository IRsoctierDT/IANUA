What it does

Four domains, one platform

Every component ships with least privilege, auditability, and defense-in-depth as first-class requirements.

🛡️
SOC Automation
JSON and plain-text log triage with 0–100 severity scoring, structured evidence capture, and human-readable incident reports — all from a single Python pipeline.

🎯
MITRE ATT&CK Mapping

14 tactics Confidence scoring Structured output Technique chaining

RAG Knowledge Pipeline
Local-first document ingestion with lexical and semantic retrieval. Reports are automatically grounded in the cited cybersecurity corpus — every citation is traceable.

Twelve typed Python agents coordinated by an orchestrator. Each agent validates its own input, emits structured output, and requires human approval for irreversible actions.

Get started

Up in three steps

Python 3.11+ and Ollama are the only prerequisites.

1
Clone & install 
# clone the repo
git clone https://github.com/IRsoctierDT/IANUA

cd IANUA
pip install -e ".[dev]"
2
Configure & run CI 
# copy environment template
cp .env.example .env

# run full quality gate locally
python -m pytest
ruff check .
mypy agents scripts tests
bandit -r agents scripts
3
Run the pipeline 
# analyse a single log line
python cli/run_incident.py \
  --log "Failed password for root \
  from 203.0.113.42 port 22"

# or process every line in a log file
python cli/batch_run_incidents.py \
  --file sample-logs/structured_events.json
